# F2F — frame-to-frame протокол тестовой сборки VoxelCore

Выжимка спецификации рабочего каталога (`agents/F2F.md`, §0–§3, §8, §10) — только то, что нужно ядру и проектам.
Полная история (Java-сторона эталона, слои рендера, lockstep-сервер) переедет в документы проекта паритета (волна 6).

## 0. Изоляция от Windows (правило пользователя, исполняется кодом)
ПК используется во время тестов: **результат не должен зависеть от фокуса, окон, курсора и ввода пользователя**.
- Снимок — только из кадрового буфера (FBO фиксированного размера), не захват окна; `normal` и `hidden` побайтно равны.
- Ввод — только командой `input`: под `--f2f` GLFW-колбэки ввода не ставятся, курсор не захватывается, окно не берёт фокус
  (`WS_EX_NOACTIVATE`), крестик/Alt+F4 игнорируются (выход — `quit`), буфер обмена свой.
- Время — виртуальное (`--f2f-clock virtual`, кадры только по `step`) или стенное (`realtime`, для замеров), ввод изолирован в обоих.
- Лаборатория проверяет это после первого `hello`: `flags.input == "isolated"`, `flags.clock` = запрошенным, `version` =
  `f2f_version` движка аренды (иначе дерево процессов убито: `isolation-failed` / `engine-mismatch`).

## 1. Транспорт
TCP `127.0.0.1:<порт>` (порт аренды из пула демона), одна строка JSON = запрос, одна строка = ответ, UTF-8, `\n`.
Запрос `{"id": 17, "cmd": "step", "args": {...}}` → `{"id": 17, "ok": true, "result": {...}}` или
`{"id": 17, "ok": false, "error": "...", "where": "..."}`; незнакомая команда — `unknown-command`. Строки ответа проходят
санитайзер (невалидный UTF-8 → cp1251 или `\xNN`; ответ не бросает исключений).

Ключи движка: `--f2f <порт>`, `--f2f-size WxH` (кадр FBO), `--f2f-clock virtual|realtime`, `--f2f-window normal|hidden`.
Ядро добавляет `--f2f-clock/--f2f-window` **до `--`** (после — аргументы проекта) и только если образ exe их знает.

## 2. Команды движка
| cmd | args | result |
|---|---|---|
| `hello` | — | `impl`, `version` (`0.31-f2f` / `0.32-f2f` / `0.32.7-f2f`), `w`, `h`, `frame`, `time`, `fixed`, `screen`, `flags {clock, input, window}`, `gl {renderer, vendor, version, glsl}`, `build {commit, dirty, flags}`, `time_epoch` |
| `mode` | `{fixed, seed, ...}` | фиксирует время, сидирует ГСЧ, сбрасывает таймеры шейдеров (`time_epoch`++): кадр после `mode` не зависит от числа кадров до него |
| `step` | `{ticks, frames, partial}` | N тактов, затем M кадров; `{tick, frame}`; в `realtime` — ошибка `clock-realtime` |
| `input` | `{keys, mouse{dx,dy,buttons,wheel,x,y}, chars}` | состояние на следующий шаг; в 0.32+ через `Input::simulate*` |
| `shot` | `{path}` | `{w, h, sha256}` — кадр FBO; в 0.32+ файл побайтно равен `gui.screenshot()` + `Canvas:encode("png")` |
| `render` | слои | слои рендера (sky, clouds, terrain, water, entities, particles, weather, selection, hand, hud) |
| `perf` | `{start, trace}` / `{stop}` / `{dump}` | фазы кадра (µs), Chrome trace JSON |
| `selftest` | `{throw}` | проверка санитайзера |
| `quit` | — | корректный выход |
Пак может добавить свои команды обработчиком Lua (`f2f` в глобальном окружении тестовой сборки: 5 функций).

## 3. Точки в кадре
Под `--f2f` цикл движка ждёт команду; `step` вызывает `time.update(virtual)` и один проход `updateFrontend/renderFrame` на
кадр; `input` пишет в `Input` в обход GLFW; `shot` читает пиксели после рендера до swap. `--test` под `--f2f`: конец теста
ловит раннер лаборатории (маркер `[lab-vctest] script finished` → `quit`), проверки `isFinished` в `run_loop` нет.

## 8. Размер кадра
Один стандарт **854×480** для всех агентов и сценариев. Другой размер — только явно в поле `"size"` сценария и сразу для
обеих сторон; снимки разного размера не сравниваются (харнесс отказывает).
