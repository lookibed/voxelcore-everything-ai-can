# wasmrt demo

Обычная C-программа с `main()` и стандартной libc, запущенная паком `wasmrt`: плазма в
собственном кадровом буфере 160×100 (`vc_gfx_present`, графика `canvas`), приветствие из файла
пака (`fopen("greeting.txt")`, каталог `data`), долгий расчёт до первого кадра, `printf` в лог
движка. Пробел — синий канал на максимум, `q` — выход (`exit 0`).

Исходник и `build.sh` — Spider, `tests/manual/wasmrt-demo` (собран с `--yield-every 20000`).

VoxelCore 0.32.1 (06–07.10): без правок, тестовая сборка 0.32 с res 0.32.1 — 120 кадров за 3.0 с (темп самой программы).
