# gpu_worldgen_light — свет неба в шейдерах пака вместо расчёта движком (дополнение к gpu_worldgen)

Пак-дополнение к `gpu_worldgen` (12.10, агент gpu_pack2). Движок не менялся. Подробно, числа и кадры — README пака
`gpu_worldgen` (раздел «Свет в шейдерах») и `agents/research/GPU_WORLDGEN.md` («Свет»).

**Что делает.**
1. **Выключает небесный свет движка свойствами блоков**: `content.json` перечисляет `base:*` (все 26 блоков base) и
   `gpu_worldgen:*` (4 блока), файлы `blocks/base/<имя>.json`, `blocks/gpu_worldgen/<имя>.json` — `{"sky-light-passing": true}`.
   Движок (`ContentUnitLoader::loadDefs`: `builder.create` возвращает уже существующее определение, `loadUnit` дописывает
   только заданные ключи) меняет у существующих блоков одно свойство. Тогда `Lighting::prebuildSkyLight` ставит небо 15 во все
   клетки столба, `buildSkyLight` не заводит заливку (ни одна клетка не «под крышей»), остаётся только проход по чанку и
   граница (`onChunkLoaded(expand)`: 16384 клетки границы с небом 15 — нижний предел цены). Свет ламп (`emission`,
   R/G/B) движок считает как прежде. Id блоков не меняются — хэши миров те же.
2. **Считает уровень неба в шейдерах мира** (`shaders/main.glslf`, `translucent.glslf` = 0.32.1 + `lib/gwl_light.glsl`):
   по высотам столбцов, которые считает GPU-цепочка RLE пака `gpu_worldgen` из тех же вокселей, что пишутся в мир
   (функция плотности + деревья): верх и низ вокселей, закрывающих небо. Lua (`modules/light.lua`) кладёт их в регион атласа
   `textures/blocks/gwl_world.png` (512x520, самая высокая текстура — упаковщик ставит её в (2, 2)). Клетка перед гранью
   выше верха или ниже низа столба — небо; иначе 15 − манхэттенское расстояние до открытого на её высоте столба (≤ 14),
   не ниже `GWL_FLOOR` (0.35); тень солнца — шаги по верхам к солнцу; AO — функцией плотности генератора
   (`lib/gwl_density.glsl`, собирается `tools/gpu_worldgen_light_build.py` из `gpu_worldgen/shaders/gpu_worldgen.glsl`).
   Режим `GWL_MODE 1` — первый вариант: лучи по функции плотности прямо во фрагменте (дорого, см. README gpu_worldgen).
3. Правки игрока: `on_block_placed/broken/replaced` → столб пересчитывается по `block.get` в следующем кадре.

**Ограничения.** Только для миров `gpu_worldgen` с `gen.cfg.rle = true` (высоты даёт цепочка RLE); в другом мире
небесного света нет (всё освещено). Модель «высоты столбов» — 2.5D: свет в многоярусных полостях приближённый (нет
заливки по 3D-путям). Сущности и рука освещаются небом движка (15 везде). На 0.31 шейдеры не проверялись (только 0.32.1).
`tools/gpu_worldgen_light_build.py --check` — сверка `lib/gwl_density.glsl` с шейдером генератора.
