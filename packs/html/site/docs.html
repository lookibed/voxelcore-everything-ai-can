Конвейер

Обычная программа на C, Java или Rust собирается в WebAssembly (wasi-sdk или TeaVM 0.10.2), затем Spider печатает из неё Lua-модуль, а пак wasmrt запускает его внутри VoxelCore по манифесту wasm.json.

  1. Компиляция в .wasm — модель main (_start) или frame (экспорт vc_frame).
  2. Трансляция: spider-cli file.wasm -t lua-no-ffi.
    • --yield-every N — точки уступки в циклах;
    • --memory table|bytearray — модель памяти;
    • --saturating-truncation — семантика Java (int).
  3. Раскладка в пак и запуск из меню «Сценарии».
Целесообразность не наш конёк: нестандартные пути — Java → wasm → Lua, растеризация на GPU в UI-шейдере — исследовать и доводить, а не отвергать. — правила пользователя, AGENTS.md

Сборка и раскладка

Всё собирается из Spider одной командой; проверки бывают быстрые (без движка) и полные:

# собрать и разложить в паки
Hosts/VoxelCore/pipeline/deploy.sh quake  # pong doom … all
Hosts/VoxelCore/pipeline/verify.sh quick
# этот сайт
tests/manual/real-world-html/build.sh && ./deploy_pack.sh

Манифест пака

Поле graphics выбирает вывод, files — каталог, видимый программе как корень:

{
  "module": "html:modules/html.lua",
  "graphics": "canvas",
  "files": "html:site"
}

Прокрутка: колесо мыши, полоса справа, ↑ ↓, PgUp PgDn, Home End.

Стек этой страницы

  • litehtml + gumbo — разбор HTML5, каскад CSS, flex, таблицы, layout;
  • свой растеризатор — заливки, скругления, рамки, градиенты, box-shadow;
  • stb_truetype — шрифты Inter и DejaVu с кириллицей, настоящий курсив и жирный;
  • stb_image — PNG / JPEG, уменьшение с усреднением;
  • QuickJS-NG — ES2023, DOM на JS поверх нативного __dom.
Шрифты. Inter — SIL Open Font License 1.1; DejaVu — свободная лицензия Bitstream Vera. Файлы лицензий лежат рядом со шрифтами в site/fonts/.
