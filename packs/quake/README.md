# Quake (wasmrt)

Quake (порт [quakegeneric](https://github.com/erysdren/quakegeneric), GPL-2) как обычная
C-программа: собран wasi-sdk в WebAssembly, оттранслирован Spider в Lua и запущен паком
`wasmrt`. Данные — shareware-эпизод id Software (`data/id1/pak0.pak`, лицензия
`LICENSES/QUAKE-SHAREWARE-SLICNSE.TXT`: бесплатное некоммерческое распространение).
Файлы читаются обычным stdio через WASI; `setjmp/longjmp` заменены (без исключений wasm
`Host_Error` становится фатальным).

Кадр 320×240 с палитрой отдаётся хосту (`vc_gfx_present_indexed`), а цвет подставляет GPU:

| манифест | где | как рисуется |
|---|---|---|
| `wasm.json` | меню и мир (оверлей HUD, так пак запускается в мире) | canvas + GPU: индексы по 4 в тексель и палитра в одной текстуре, цвет — шейдер UI пака wasmrt |
| `wasm_cpu.json` | меню / оверлей | canvas + CPU: перевод индексов в RGBA на Lua (для сравнения) |
| `wasm_post.json` | мир, только для сравнения | постэффект: кадр, уменьшенный до 120×90 (предел uniform-массива), и палитра в шейдере — мыло, по умолчанию не используется |

Замеры (эта машина, 0.31): показ кадра — GPU 0.16–0.27 мс, CPU 0.68–0.78 мс, постэффект
1.6 мс (уменьшение и упаковка на Lua); в текстуру уходит 78 КБ за кадр вместо 307 КБ. Сам
Quake (программный рендер на Lua) — `timedemo demo1` (`wasm_timedemo_gpu.json`) **35.8–37.0 кадров/с**
(29.09, модуль с `spider-cli --memory-helpers notail`), до этого 23.6–25.8 кадров/с при любом способе
показа; в игре ~37 кадров/с.

11.10 (рантайм Spider: i32-сравнения/расширения без ветвлений, константы f64 литералами; старый модуль — `quake.lua.bak`):
timedemo на аренде 0.31 — до 38.4/41.7/41.4, после 39.1/39.9/37.3 кадров/с (`artifacts\lab\runs\20261011_200616…`,
`…202737…`, `…202847…`, `…202951…`), кадры в стоковом LuaJIT — те же хеши. Вариант `spider-cli --f32 number` (f32 — число Lua):
34.0/37.2/48.8 и 52.8/36.4/35.6 — разброс больше выигрыша, в пак не взят.

Модуль транслируется с `--memory-helpers notail` (по умолчанию в `build.sh`; `MEMORY_HELPERS=tail` —
как раньше): в хелперах памяти рантайма Spider `buffer_*` нет хвостовых вызовов (`return (f(...))`
вместо `return f(...)`), и LuaJIT не уводит трассу из хелпера в вызывающую функцию, где она срывалась.
Замер вариантов — `export/membench/results.txt`. После конца timedemo в логе `Host_Error (longjmp) -
stopping` и `[wasmrt] crash ...` — так было и до флага (выход Quake из демо), это не падение модуля.

## Управление

Две схемы, переключаются кнопкой **«Управление: WASD+мышь / стандарт»** на странице (и в
HUD-оверлее) и действуют сразу на запущенную игру; выбор хранится в `config:quake/controls.txt`
(`modern` / `classic`), без файла — поле манифеста `"controls"` или `modern`.

- **WASD+мышь (по умолчанию):** W/A/S/D — ход, мышь — взгляд всегда (`+mlook`, `lookspring 0`),
  ЛКМ — огонь, ПКМ — прыжок, Space — прыжок, Shift — бег (как в оригинале), 1–8 — оружие,
  `/` — следующее оружие, `` ` `` — консоль. Курсор захватывается (`vc_mouse_grab`), пока идёт игра
  (`key_dest == key_game`, не демо), и отпускается в меню/консоли Quake (Esc) — тогда доступны кнопки
  страницы. Колесо: `MWHEELUP` = `impulse 10`, `MWHEELDOWN` = `impulse 12`, но при захваченном курсоре
  GUI движка прокрутку не отдаёт (у Lua нет API колеса; ловится прозрачной scroll-панелью), поэтому
  колесо работает только без захвата (например, листает консоль).
- **Стандарт:** привязки `default.cfg` из pak0 (стрелки, Ctrl — огонь, Space — прыжок...), взгляд
  мышью — с зажатой правой кнопкой, как раньше.

Реализация — без изменения логики игры: программа (`qg_wasmrt.c`) каждый кадр спрашивает режим у
расширения пака (`modules/qg_host.lua`, импорт `vc.qg_controls`) и при смене добавляет в буфер команд
Quake `bind ...` / `+mlook` (при старте — после `exec quake.rc`, т. е. после `default.cfg`); обратно —
восстанавливает привязки `default.cfg`. Консольная команда `qg_showbinds` пишет привязки в лог
(`[wasmrt] log: quake: controls modern, mlook 1, binds: w=+forward ...`), её же программа вызывает
после каждой смены. Демо при обеих схемах идут кадр в кадр как раньше (хэши кадров 100/200/300 в
`run_luajit.lua` совпадают со старой сборкой).

## Запуск

- Меню «Сценарии» → `quake [quake]` (`scripts/app/quake.lua`): страница wasmrt `wasmrt_app` с
  `quake:wasm.json`, кнопка Back — назад в меню.
- В мире — HUD-оверлей (`scripts/hud.lua`).

Исходники и сборка: Spider, `tests/manual/real-world-quakegeneric` (`src/qg_wasmrt.c`,
`build.sh`, `run_luajit.lua`).
