# Тестовые сценарии паков (gameboy, videoplayer, doom, wasmrt, quake, eaglercraft)

Не входят в паки. Lua-сценарии запускаются через `res/project_client.lua`: MCP-обёртка
`vc_start(script="user:tools/scenarios/<файл>.lua")` или вручную через `AUTORUN_APP_SCRIPT`.
JSON-сценарии в `eag/` — не Lua: их выполняет сам MCP-сервер (`scenario_run`), шаг за шагом вызывая свои
инструменты `eag_*` / `vc_*`.
Результаты пишутся в `latest.log` с меткой в квадратных скобках.

кликами по меню; пункт меню — для пользователя при сдаче, его проверяют один раз `vc_click`.
