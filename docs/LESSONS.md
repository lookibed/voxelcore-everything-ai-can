# Грабли (каркас волны 1; перенос agents/LESSONS.md — волна 5)

- Windows-Python из WSL не видит переменные окружения без `WSLENV` (`LAB_SKIP_ENGINE`, `LAB_OWNER`, `LAB_PORT`).
- Логи Windows-скриптов — cp866/cp1251; декодер лаборатории угадывает кодировку построчно (`vclab/scenario/decode.py`).
- `--test` под `--f2f`: движок не выходит сам после теста — раннер ставит маркер и шлёт `quit`.
- Непойманная ошибка Lua в тесте 0.32 = `abort()` → код 0xC0000409, а не 1.
- `stdin` движка на Windows читается только после `_kbhit()` консоли: вид с `stdin_poke = "console"`.
- Перезапуск демона убивает аренды (Job Objects) — поэтому drain/upgrade и роли (02.10: потеряна чужая сессия).
- SQLite истории пишет только демон (Windows): через `/mnt/d` из WSL блокировки DrvFs ненадёжны.
- Фоновые ожидания с неверным шаблоном молчат до таймаута — шаблон проверять на существующем логе.
