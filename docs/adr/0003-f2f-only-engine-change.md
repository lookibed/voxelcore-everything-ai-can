# ADR 0003: тестовая сборка F2F — единственная правка движка (30.09–01.10.2026)

**Контекст.** Порту нужен паритет «кадр в кадр» с эталоном, а пользователь запретил менять движок «кроме штук для
frame2frame pixel2pixel тестирования и автоматизации». Снимки через захват окна и ввод ОС зависят от фокуса и мешают
пользователю, который работает за ПК во время тестов.

**Решение.** Патч F2F (`f2f/patches/`, ветки в приватном `lookibed/voxelcore-f2f`): сервер команд на TCP `127.0.0.1`,
шаг такта/кадра, снимок из FBO фиксированного размера, синтетический ввод в `Input` движка, изоляция от ввода ОС (колбэки
GLFW не ставятся, окно без фокуса), часы `virtual`/`realtime`, сброс таймеров (`mode`), фазы кадра (`perf`), слои рендера.
Сборка — релизным рецептом (тот же LuaJIT). Протокол одинаков для всех версий; `hello.version` различает сборки.

**Последствия.** Каждая новая версия движка требует переноса патча (`f2f/README.md`) и записи в реестр. Игра, рендер, API —
только паками. Правка движка вне F2F — нарушение, каждую правку называть в отчёте.
