# ADR 0001: отдельный репозиторий экосистемы, ядро без проектов и путей машины (29.10.2026)

**Контекст.** Лаборатория росла внутри рабочего каталога движка (`tools/lab`, `tools/mcp`), с путями одного ПК и с
проектами (alphamine, olife, wasmrt, eaglercraft) рядом с ядром; перенести на другую машину или дать другому агенту нельзя.
**Решение.** Ядро — пакет `vclab` (перенос по поведению, без переписывания логики); пути — только `machine.toml`; версии
движка — `engines/registry.toml`; проекты — `projects/<имя>/` с точками расширения (plugin.py, cli.py, mcp_tools.py,
sup_panel.js). Проектное, что было внутри ядра, вынесено в `projects/olife` и `projects/_parked` до волны 6.
**Последствия.** Команды без `--project` берут `[defaults] project` lab.toml (раньше — зашитое имя); журнал MCP и
`scenario_run` ждут поставщика состояния от проекта; общий демон рабочего каталога и новый не должны делить порт 25700.
