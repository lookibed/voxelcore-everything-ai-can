# ADR 0010: проекты — плагины, ядро без игр (01.10.2026, вынос — 29.10.2026)

**Контекст.** Пользователь одобрил инфраструктуру с условием: «агенты и инструменты должны быть унифицированы, чтобы
последующие проекты тоже могли это юзать». Со временем в ядро всё же проникли имена проектов (CLI `lab olife`, панель
supervisor, наборы журнала MCP с `eag_*`/`am_*`).

**Решение.** Проект = `projects/<имя>/project.toml` (виды, каталоги, сравнение, golden, ворота, play) + `plugin.py`
(возможности, хуки и шаги сценариев, перф, supervisor) + точки расширения `cli.py` (`lab <проект> …`), `mcp_tools.py`
(инструменты и наборы журнала MCP `voxelcore`), `sup_panel.js` (секции панели). Демон перечитывает проекты раз в секунду;
ошибка плагина оставляет прежнюю версию. Проектное из ядра вынесено в `projects/olife` и `projects/_parked`.

**Последствия.** Команды без `--project` берут `[defaults] project` из `lab.toml` (раньше — зашитое имя). Приёмка правки ядра
показывает второй проект на тех же инструментах. Проекты переезжают по одному (волна 6, `docs/PROJECTS.md` §8).
