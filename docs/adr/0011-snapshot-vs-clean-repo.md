# ADR 0011: снимок рабочего каталога и чистый репозиторий (23–29.10.2026)

**Контекст.** Всё делалось в каталоге установки движка (паки, лаборатория, MCP, документы агентов — вперемешку, с путями
ПК и хронологией волн). Пользователь хочет продолжить на другом ПК другим агентом, не потеряв возможностей.

**Решение.** Два репозитория. Снимок рабочего каталога — приватный `lookibed/voxelcore-workbench-snapshot-2026-10`: резерв
как есть, история решений. Чистый — `lookibed/voxelcore-everything-ai-can`: ядро `vclab`, реестр движков, F2F-патчи и
протокол, проекты как плагины, документы, написанные для нового агента (без хронологии). Ветки F2F — в
`lookibed/voxelcore-f2f`. Перенос — копированием, по волнам: 1 — ядро; 4 — рецепт сборки F2F; 5 — документы; 6 — проекты
(vc → wasmrt → olife → alphamine); 7 — релизы exe F2F и bootstrap.

**Последствия.** Пока перенос не закончен, оба живут рядом: общий демон снимка занимает порт 25700, чистый работает через
изолированные демоны. Старые документы — источник фактов, не инструкция; при расхождении верен код.
