# ADR 0004: версия движка — измерение лаборатории (02.10.2026, 0.32.7 — 22.10.2026)

**Контекст.** Работа перешла с 0.31 на 0.32 (Olife), потом на 0.32.7; паки 0.31 остаются. Прогоны разных версий смешивались
бы в истории и воротах, а сборка «не той» версии давала бы ложные выводы.

**Решение.** Реестр `engines/registry.toml` (происхождение, sha256, патч, `f2f_version`), раскладка — корни `machine.toml`.
Вид выбирает версию (`engine = "<id>"`, `by_engine`), аренда — `--param engine=<id>`. Демон сверяет `hello.version` с
`f2f_version` (иначе `engine-mismatch`). Аренда, прогон, история, ворота и панель несут `engine_version`; основание ворот —
только той же версии.

**Последствия.** Сравнение версий — в истории и на панели, не в храповике. Golden — по версии (ADR 0008). Новая версия —
секция реестра + `ORIGIN.md` + F2F-сборка (`f2f/README.md`), без правок ядра.
