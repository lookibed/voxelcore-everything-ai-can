# ADR 0006: правки ядра — на изолированном демоне (02.10.2026)

**Контекст.** Проверять правку ядра нужно на живом демоне, а общий перезапускать нельзя (ADR 0005).

**Решение.** `lab daemon start --isolated [--port 25800..25849]`: свой порт, свой каталог `<work_root>\lab\isolated\<P>`
(state, inst, journal, runs, history, audit), свои порты аренд `25850 + 10·(P − 25800)` … +9, без зеркала `latest.log` и без
сторожа (процессы общего демона ему чужие). Сам по себе не поднимается (опечатка в `--daemon` не создаст лишний демон); права
уровня демона — у admin и у `starter`, кроме `golden promote` (golden общие).

**Последствия.** Агент: правка → изолированный демон → тесты и прогоны → отчёт главной сессии → `lab daemon upgrade` на общем.
Новый репозиторий на машине со старой установкой работает только через изолированные демоны (порт 25700 занят чужим).
