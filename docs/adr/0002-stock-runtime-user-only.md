# ADR 0002: стоковое окно движка — только пользователю (01.10.2026)

**Контекст.** Агент для замера fps запустил стоковый `VoxelCore.exe` в обычном режиме: окно захватило курсор
пользователя, реагировало на его мышь и открывало паузу при смене окна. Пользователь: «рантайм только для меня и тебя как
финальная проверка по запросу или релизу, разово». Правило словами уже нарушалось.

**Решение.** Исполняет `vclab/policy.py`. Стоковый exe (по пути или по sha256 любой версии реестра) в тестовом виде —
отказ `policy`. Вид `role = "runtime"` создаётся только сеансом `lab play`: `--user` (владелец `user`, интерактивный терминал,
не MCP) или `--final-check --reason` (главная сессия/пользователь, запись `runtime_session`). Вид `role = "headless"`
(`--headless`, без консоли) может запускать сток: демон всё время жизни проверяет, что у дерева процессов нет окон.

**Последствия.** Агентские запуски — только тестовая сборка F2F (ADR 0003), замеры реального времени — она же с часами
`realtime`. Игра пользователя — с отчётом и записью в историю. Обход — только решением пользователя.
