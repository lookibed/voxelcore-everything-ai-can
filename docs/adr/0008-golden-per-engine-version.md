# ADR 0008: golden — по версии движка (22.10.2026)

**Контекст.** Кадр зависит от версии движка (шейдеры, анимации, шрифты): эталон 0.32.0 для 0.32.7 — ложная регрессия, а
затирание старого эталона лишает сравнения.

**Решение.** Эталоны и основания ворот разделены по версии. Код: история пишет `engine_version`, основание и храповик ворот —
только прогоны той же версии. Проект: отдельный `golden_dir` на версию (так сделан olife при переходе на 0.32.7:
`golden\v0327`, общий CAS `golden_store`) и exe движка/сборки в `[golden].inputs` — смена сборки делает эталон `stale`.

**Последствия.** Переход на новую версию — `lab golden regen` в новом каталоге, старый остаётся. Подстановки `{engine.*}` в
`golden_dir` ядро сейчас не раскрывает (`base_ctx` без движка) — версия пишется в путь явно.
