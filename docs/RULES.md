# Правила (каркас волны 1; полный текст — волна 5, источник — AGENTS.md рабочего каталога)

- **Ввод ОС запрещён, тесты не зависят от Windows**: движок агентами — только арендами в режиме `--f2f` (проверка
  `hello.flags.input == "isolated"`, иначе экземпляр убит); снимки — из кадрового буфера (F2F `shot`); свои скрипты с
  `SendInput`/`mouse_event`/`SetForegroundWindow` не писать. Это исполняет `vclab/policy.py`, а не слова.
- **Стоковый exe — только пользователю**: `lab play <проект> --user` (его терминал) или `--final-check --reason` главной
  сессии; в тестовых видах — отказ; без окна (`role = "headless"`) — можно.
- **Замеры — только на свободном ПК** (`lab perf` ждёт простоя, иначе `contended`, такие прогоны не идут в ворота).
- **Кадр тестов — 854×480**; другой размер — только явно в сценарии и для обеих сторон.
- **Демон общий**: агент не делает `lab daemon stop|restart|upgrade`, правки ядра проверяет на изолированном демоне.
- **Движком владеет один агент** за раз; «стоп» пользователя = снять всё (`lab release --all --force`).
- **Не торопиться**: каждое утверждение — с выводом/цифрами; замеры сверять с записанными.
- **Движок менять только для тестов** (F2F-патч); игра — паками на стоке.
